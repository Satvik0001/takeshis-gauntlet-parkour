# Takeshi's Gauntlet: Parkour 🏃‍♂️💥

**Takeshi's Gauntlet: Parkour** is a 3D parkour and obstacle-course prototype built in **Unity and C#**, inspired by the chaotic obstacle challenges seen in shows like *Takeshi's Castle*.

The goal is simple:

> **Reach the finish line without falling, getting knocked off, or failing the obstacles.**

The game focuses on movement, jumping, timing, physics-based obstacles, checkpoints, and progressively challenging level design.

## 🎮 Gameplay

The player navigates through an obstacle course filled with different challenges.

Each section requires the player to use movement and timing to progress.

Some obstacles are designed to:

* Knock the player away
* Make the player fall
* Require precise jumping
* Test movement and timing
* Force the player to choose the correct path

If the player fails an obstacle, they can respawn at a checkpoint and attempt the section again.

## 🧩 Level Design

The prototype is designed around individual obstacle sections rather than one continuous environment.

Different sections introduce different challenges, allowing the difficulty to gradually increase.

The course can include challenges such as:

**Slippery Platforms → Guess Doors → Moving Platforms → Fake Floors → Knockback Obstacles → Rotating Obstacles → Rolling Logs → Final Obstacle Section**

This structure allows new mechanics to be introduced progressively while keeping the gameplay easy to understand.

## 🎯 Objective

The player's objective is to:

**Navigate the obstacle course → Avoid the hazards → Reach the checkpoints → Complete the course.**

Failure is part of the gameplay. Falling from an obstacle sends the player back to the appropriate checkpoint so they can try again.
